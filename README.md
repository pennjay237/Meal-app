# Food Ordering App with MealDB API

![App Screenshot](screenshot.png)

This is a React-based food ordering application that uses the MealDB API to display and manage meals. The app includes both customer-facing and admin interfaces.

## Features

- **Landing Page**: Browse available meals with images and prices
- **Product Details**: View meal details, nutritional information, and ingredients
- **Checkout Flow**: Complete payment for orders
- **Admin Dashboard**: Manage meals (add/update/delete) with password protection
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Context API**: State management throughout the application

## Technologies Used

- React (v18+)
- React Router (v6+)
- Context API (State Management)
- CSS Modules (Styling)
- MealDB API (Data Source)
- React Icons (Optional)
